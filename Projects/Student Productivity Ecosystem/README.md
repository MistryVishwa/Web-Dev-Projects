# Student Productivity Ecosystem (Aura Study Ecosystem)

A premium, glassmorphic, unified student productivity workspace built entirely from scratch with HTML, CSS, and Vanilla JavaScript. The system enables students to manage study schedules, target learning goals, track assignments, monitor weekly focus metrics, simulate LMS integration, earn level-up badges, consult an AI-powered study companion, and practice mental well-being exercises.

## 🌟 Features

1. **Study Schedule Management**: Set up customizable time slots with visual categories (Exam, Revision, Homework, Lab) and click to simulate alerts/notifications.
2. **Learning Goal Setting**: Input goals, define sub-milestones, check them off, and see the radial SVG progress tracker update in real-time.
3. **Assignment Tracker**: Drag-and-drop or status-toggle task board with categories (To Do, In Progress, Submitted).
4. **Productivity Metrics**: A custom weekly focus bar chart built dynamically with SVG representation to visualize study hours.
5. **Academic Growth Insights**: Personalized recommendation system suggesting topics, resources, and time-management improvements based on current statistics.
6. **Resource Library**: Bookmark and tag study resources, filtering them dynamically.
7. **Collaboration Tools**: Connect with study peers, simulate peer chat sessions, and review group progress.
8. **Mobile Accessibility**: Fully responsive sidebar layout designed with glassmorphic cards and flex-grid overlays.
9. **LMS Integration Simulator**: Simulates fetching modules, homework, and grade statistics directly from LMS platforms (e.g. Canvas, Blackboard).
10. **Gamification Elements**: Experience Points (XP) reward tracker, level progression, and achievement badge unlocking.
11. **AI Study Companion**: An interactive chatbot interface that simulates AI study recommendations, virtual scheduling help, and answers study prompts.
12. **Mental Health & Stress Support**: Breathing exercise screen (inhale/hold/exhale pacing circle) and a white-noise sounds player.

## 🛠️ Technology Stack
- **Structure**: Semantic HTML5
- **Styling**: Vanilla CSS3 (Custom Glassmorphism, Theme Variables, Responsive Grid)
- **Logic**: Vanilla ES6 JavaScript (Interactive DOM, LocalStorage caching, SVG Renderers)
- **Icons**: Lucide Icons (CDN)
